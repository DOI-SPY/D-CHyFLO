# 方法概述

## 1. 物理基线

水库状态由水位–库容–面积（H–V–A）单调曲线、尾水位曲线、动态水头、机组出力边界与日水量平衡共同约束。`PhysicalCurves`默认拒绝H–V–A范围外外推；尾水和机组曲线的端点延拓会显式返回越界标记。

## 2. FPV与寒区可用率

逐时太阳位置、辐照换算和组件温度通过pvlib实现。寒区修正作为Tier-1参数情景处理，只表示结冰、积雪、低温和大风对能源可用率的压力，不是系泊或结构安全模型。

## 3. 协同调度

能量调度在水量、库容、机组和共享送出约束下最大化水光联合送电。碳感知调度采用词典序结构：先保持登记的能量下界，再根据逐时模型化碳信号优化替代减排价值。模型化信号不能称为实测边际排放。

## 4. 边际水碳价值

对某月总入流水量施加正负对称扰动，分别重新求解年度调度，并以中心差分计算边际碳价值。该指标是约束条件下的模型影子价值诊断，不是水价、碳价或可交易资产价格。

## 5. 动态生命周期碳

年度账本显式记录初始制造、运行替代减排、设备性能衰减、替换、退役、电网碳因子变化和条件水体响应。只有在功能单位、时间边界和归属规则兼容时，分量才允许合并。

## 6. 不确定性

情景集合和有界参数空间不附加经验概率。分位数、CVaR和负值占比只能解释为预定义集合或采样边界内的决策诊断，不解释为现实发生概率。
