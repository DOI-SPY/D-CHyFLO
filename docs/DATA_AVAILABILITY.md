# 数据可用性

## 仓库内数据

`examples/synthetic_reservoir/data/`中的文件均为专门构造的合成数据，仅用于测试接口、单位和运行流程，不代表任何真实水库。

## 未公开数据

本仓库不包含：

- 任何真实水库的日、旬、月或小时长系列水情；
- 调度手册、工程曲线原件、内部运行记录和原始工作簿；
- 能够逆向重建真实长系列的逐时/逐日优化结果；
- 许可LCA数据库、第三方GIS/CMIP6原始文件或第三方仓库副本；
- 个人信息、访问令牌或本地绝对路径。

用户应自行获取有权使用的数据，并转换为示例所示的数据契约。不同数据源的许可和引用责任由使用者承担。
