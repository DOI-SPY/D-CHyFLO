# 声明边界

| 可说 | 必须同时说明 | 不可升级为 |
|---|---|---|
| 碳感知调度可改变用水时序 | 使用模型化碳信号 | 真实电网运行效果 |
| 边际水碳价值具有时序差异 | 仅在登记模型和扰动边界内 | 市场水价或碳资产价值 |
| 风险准则选择不同设计 | 情景集合为预定义有界集合 | 唯一工程推荐 |
| 动态净碳可被联合压力翻转 | 代理生命周期和条件水体响应 | 最终场址LCA |
| CMIP6窗口用于压力测试 | 不是未来入流预测 | 发生概率或确定性预报 |

关键证据门采用非补偿规则：缺失实测边际排放、工程BOM、寒区安全、过程LCA或物理水体响应时，其他模块的数值精度不能把相应场址结论从HOLD升级为PASS。
