# Outputs

`scripts/run_all.py` writes the current run to `outputs/`, which is ignored by Git.
The five core tables are:

- `operational_attribution.csv`
- `mcv_summary.csv`
- `capacity_summary.csv`
- `lifecycle_summary.csv`
- `break_even_summary.csv`

`frozen_result_check.csv` checks the registered headline values. The example input is
synthetic, so its calculated values are demonstrations rather than Nierji results.
